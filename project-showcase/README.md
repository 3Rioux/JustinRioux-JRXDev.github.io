# Project Showcase

This project showcases various projects I have worked on, categorized into different sections such as Webpages, Website Features, 2D Games, Multiplayer Games, Arduino, and more. Each project can belong to multiple categories and displays relevant information about the project.

## Project Structure

The project consists of the following files:

- **index.html**: The main HTML structure for the project showcase page.
- **styles/showcase.css**: CSS styles for the project showcase page, ensuring a responsive and visually appealing layout.
- **scripts/showcase.js**: JavaScript code that adds dynamic functionalities, such as filtering projects by category and displaying project details.

## Features

- Categorization of projects into multiple sections.
- Display of skills used/learned, roles, project names, descriptions, and team member counts.
- Responsive design for optimal viewing on various devices.
- Interactive filtering options to view projects by category.

## Setup Instructions

1. Clone the repository to your local machine.
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory.
   ```
   cd project-showcase
   ```
3. Open `index.html` in your web browser to view the project showcase page.
